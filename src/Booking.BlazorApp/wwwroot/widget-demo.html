Zambiq booking widget — demo

Vervang RESTAURANT_ID hieronder door een echt restaurant-id. Deze pagina kan ook vanaf een ander domein worden geopend; pas dan de src van het script aan naar je Zambiq-host.

Insluitvoorbeeld

<div data-zambiq-restaurant="RESTAURANT_ID"></div>
<script src="https://<zambiq-host>/widget.js" async></script>
